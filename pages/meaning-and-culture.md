The types of semiotics used in algorithmic feeds include things like misleading pictures and persuasive wording. These semiotics can influence the overall message, and create a different meaning for each individual, depending on how it's interpreted. The more a certain type of  message comes into a user’s feed, it the more it starts to create a trend with common themes. This can start to send a pretty direct message to the viewer.

For example, if someone is constantly interacting with content related to one political party, they are more likely to be persuaded into thinking in line with that party, because that's the only opinion they consume. When the user is only getting one type of content, and isn’t seeing things from other parties, it creates a false narrative. This illustrates the large role that semiotics play in the media, as well as their influence on how messages can be received.
