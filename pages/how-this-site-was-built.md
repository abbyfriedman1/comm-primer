This section explains the process behind the site's tool stack, layout, and content workflow.

## Boilerplate Process Summary:

- The site uses Jekyll with a custom accessible layout and a pastel pink professional color palette.
- The structure includes a home page plus six analysis pages, leaving content ownership to you.
- A GitHub Actions workflow builds the site automatically on every push to the `main` branch.
- The build setup uses repository-aware configuration (`url` and `baseurl`) so it works correctly on GitHub Pages.

## About Agent Involvement:

An AI coding agent scaffolded the site structure, created starter content, added accessibility-focused markup, and configured automation so you can concentrate on writing and revising the substantive theory analysis.

## About Human Involvement:

A human wrote their own analysis on the topic of algorithmic feeds and how they shape individuals beliefs and views.
